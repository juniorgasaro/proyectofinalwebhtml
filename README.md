# Corpora Estética Corporal

## Descripción

Corpora Estética Corporal es un sitio web desarrollado como proyecto integrador final del curso de HTML5.

El sitio presenta información sobre el centro de estética, sus tratamientos, el personal y los medios de contacto.

## Páginas del sitio

- **Inicio:** presentación general de Corpora Estética Corporal.
- **Tratamientos:** información sobre los tratamientos disponibles y sus precios.
- **Personal:** información sobre el personal del centro.
- **Contacto:** formulario de contacto, información de ubicación y mapa.
